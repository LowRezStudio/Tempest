# Tempest.Protocol

Shared gRPC/protobuf contract. Apply the [root guide](../AGENTS.md).

- Edit `.proto` sources, not generated C# or TypeScript.
- C# is generated by `Grpc.Tools` during the .NET build.
- TypeScript clients are generated into the launcher's RPC directory.
- Wire contract changes through both backend and frontend callers.

After changing a proto, run from the repository root:

```sh
dotnet build Tempest.slnx
pnpm -C Tempest.Launcher proto-generate
pnpm -C Tempest.Launcher check
```

Read the [CLI](../Tempest.CLI/AGENTS.md) and
[Launcher](../Tempest.Launcher/AGENTS.md) guides when modifying consumers.
