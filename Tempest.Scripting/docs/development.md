# Scripting builds and runtime

[Agent entry point](../AGENTS.md). Read only the sections relevant to the task.

Paths in this reference retain their original project/repository context; verify details against
current sources.

- `Tempest.Scripting/` — Rust LuaJIT modding API DLL for Paladins, Win64 and Win32 (tested on 8.1
  Win64 + Win32 and OB57 Win32; `Tempest.Scripting64.dll` + `Tempest.Scripting32.dll`, built from
  macOS with MinGW-w64 via `scripts/package.sh`; the i686 build runs LuaJIT's host tools under Wine
  and uses `panic = "abort"`; shipped mods live in `mods/<name>/`; Dear ImGui `ui` module from
  vendored cimgui under `crates/tempest-scripting/native/`, bindings regenerated by
  `scripts/gen_imgui.py`), standalone Cargo workspace; see its `README.md`

## Tempest.Scripting commands

```bash
just scripting-test              # cargo test (host, no game image)
just scripting-check             # clippy, host + x86_64-pc-windows-gnu
just scripting-build             # Tempest.Scripting/scripts/package.sh -> dist/{scripting,console,dev,lib}.tempest (both DLLs; TEMPEST_SCRIPTING_TARGETS=64|32 for one)
just scripting-run <game> [args] # build, then `tempest launch <game> --dll ...Scripting64.dll --dll ...Scripting32.dll` (the CLI injects the matching one)
```

Both DLLs cross-compile with MinGW-w64 (`brew install mingw-w64`, C and C++, x86_64 and i686
toolchains); `cross`/Docker is only the fallback. The Win32 build additionally needs `wine`
(LuaJIT's host tools must run with 32-bit pointers: `scripts/luajit-hostcc32.sh`) and is built with
`panic = "abort"` because Homebrew's i686 MinGW is SJLJ. The host build also needs a C++ compiler
(ImGui is compiled for `cargo test`). A mod's `dlls/64/` is injected into the Win64 client only and
`dlls/32/` into the Win32 client only; DLLs directly in `dlls/` (legacy layout) go to both, and any
DLL whose PE machine type does not match the executable is skipped
(`Tempest.CLI/Launcher/ModDlls.cs`, `PeImage.cs`). Logs go to `%TEMP%\tempest-scripting.log` (fresh
each run, previous run in `tempest-scripting.prev.log`; inside the Wine prefix when the game runs
under Wine); the console window doubles as a Lua REPL. Runtime settings:
`<game>/ChaosGame/Config/tempest.toml`; dev mods hot-reload from `<game>/mods/`; per-mod configs in
`<game>/ChaosGame/Config/mods/<id>.toml`. See `Tempest.Scripting/README.md`.
